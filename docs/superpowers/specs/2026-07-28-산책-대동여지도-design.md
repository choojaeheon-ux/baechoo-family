# 배추 산책 대동여지도 — 설계

날짜: 2026-07-28 · 승인: 재헌 ("고고")

## 목적

지금까지의 모든 산책을 한 지도에 누적해 "배추가 다닌 동네 지도"를 보여준다.
콘셉은 **둘 다**: 누적 경로(기본) + 정복 격자(토글).

당시 데이터 규모: 산책 78회(GPS 경로 61회, 좌표 약 4,000개, 누적 34.5km).
→ DB 변경·사전 계산 없이 클라이언트에서 즉석 계산으로 충분.

## 화면

- **진입**: 산책 탭 상단, [산책 시작]/[수동 입력] 버튼 아래 「🗺️ 대동여지도」 전폭 버튼.
- **화면**: 전체 화면 오버레이(WalkTracker 패턴, `fixed inset-0 z-[60] bg-cream`).
  - 헤더: 제목 + 닫기.
  - 통계 줄: 총 산책 횟수 · 누적 거리 · 누적 시간 · 정복한 땅(칸 · 약 N평).
    - 횟수·거리·시간은 수동 입력분 포함, 지도·격자는 GPS 경로 있는 산책만.
  - 지도: 나머지 영역 전부. 우하단(또는 헤더)에 [영토] 토글 칩.

## 레이어

1. **누적 경로(기본)**: 경로마다 반투명 초록 폴리라인(`#5b8c3e`, opacity ~0.25).
   겹치는 길은 저절로 진해짐 → 빈도 표현을 공짜로 얻는다.
2. **정복 격자(토글)**: 50m×50m 칸 중 경로가 지나간 칸을 반투명 초록으로 칠함.
   정복률 %는 분모(동네 경계)를 정의할 수 없어 쓰지 않고 **칸 수·면적(평)**으로 표기.
   1칸 = 2,500㎡ ≈ 756평.

## 격자 수학 (`lib/geo.ts`, 순수 함수 + vitest)

- 위도 스텝 고정: `LAT_STEP = 50 / 111320` (도).
- 행(row) = `floor(lat / LAT_STEP)`. 경도 스텝은 **행 중심 위도의 cos** 기반
  → 같은 행 안에서 칸이 정렬되고, 인접 행 간 폭 차이는 무시 가능(동네 스케일).
- 세그먼트가 칸을 건너뛰지 않도록 점 사이를 ~25m 간격으로 보간해 샘플링.
- API: `visitedCells(routes) → {gx, gy}[]`, `cellBounds(gx, gy) → {south, west, north, east}`.

## 컴포넌트

- `components/baechoo/WalkAtlas.tsx` (신규): 오버레이 + 지도 초기화 + 두 레이어 렌더.
  지도는 `lib/naver-maps.ts` 로더 재사용, 인증 실패 시 기존 폴백 문구.
  최초 1회 전체 경로에 fitBounds.
- `WalkList.tsx`: 진입 버튼 + `{atlas && <WalkAtlas onClose=... />}` 한 줄.

## 하지 않는 것 (YAGNI)

- DB·마이그레이션 변경 없음. 저장 로직 무접촉(순수 읽기 기능).
- 정복률 %, 새 칸 개척 알림, 기간 필터, 응가 마커 누적 표시 — 전부 v1 제외.

## 검증

- vitest: 격자 함수(행 정렬·보간·경계·중복 제거).
- `npx eslint` + `npm run build`.
- 배포 후 Playwright로 라이브 1회 실물 확인(폴링 금지 — 운영 노하우 준수).
